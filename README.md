# Vehicle Rental Management System — Course End Project Report

This repository contains an Overleaf-compatible LaTeX report adapted from the supplied course-end report template.

## Files
- `main.tex` — report source
- `College Logo Grayscale.jpg` — college logo image copied from the supplied template

## Open in Overleaf
1. Create a new Overleaf project and choose **Upload Project**.
2. Upload this ZIP file.
3. Ensure `main.tex` is selected as the main document.
4. Replace the bracketed placeholders on the title page (batch, student names, roll numbers, faculty, department, and college) with your details.
5. Compile with pdfLaTeX.

## Notes
The report describes a proposed academic system. The test table intentionally says `To be tested`; update it with actual results only after running your implementation. Adjust the technology stack to match what you build.
